# Explorer2Dialog 测试报告

功能测试使用 Windows 11 x64、.NET Framework 4.8.1 和普通用户权限。公开报告只保留测试场景、结果和汇总耗时。

## 已打开的对话框

- 在同一个资源管理器窗口依次切换至目录 C、B。记事本的「打开」对话框一直保持打开，地址栏和文件列表均同步更新，焦点留在资源管理器。目录 B 含中文、空格、`+`、`#`、`%` 和多级目录。
- 记事本的「另存为」对话框在同样条件下更新至 C，保留原文件名。核对后取消保存。
- Explorer 目标目录保持相同时，切回原对话框会保留用户手动选择的目录。关闭对话框后，在同一记事本进程重新打开，也能跳到新缓存目录。

## 应用和基础场景

| 场景 | 实测结果 |
| --- | --- |
| 联合测试程序的标准打开、另存为 | 通过。验证了文件读写、默认文件名保留、多个 Explorer 窗口和标签页。 |
| Windows 记事本的打开、另存为 | 通过。覆盖前台跳转、保持对话框打开的后台跟随和关闭重开。 |
| Microsoft Word 的打开、另存为 | 通过。使用 Windows 标准对话框，入口为 `Ctrl+F12` 与 `F12`。 |
| Microsoft Edge 打开本地文件 | 通过。使用 `Ctrl+O`。 |
| ANSYS Fluent 2025 R2 的 Read Case | 自定义文件选择窗口，跳过。 |
| ANSYS CFX-Pre 2025 R2 的 Open Case | Qt 文件选择窗口，跳过。 |
| 设置、消息窗口，以及无有效目录或缓存目录失效 | 通过。无自动导航输入。 |
| 传统 Win32 文件选择窗口 | 已验证能识别传统打开和保存界面，当前保留手动跳转。 |

`.\build.ps1 -Checks` 验证窗口生命周期、缓存代次和文件 URL 解码。桌面复现步骤见[使用说明](../README.md)。

## MSI 安装与卸载

v0.1.0 的 x64 MSI 在 Windows 11 上通过当前用户安装和卸载。安装后的程序和许可证与构建产物一致，开始菜单快捷方式指向已安装程序。卸载后确认安装文件、快捷方式和 Windows Installer 登记均已清理。

## 耗时及范围

切回已经显示的记事本对话框时，两次样本首次读到新目录的时间约为 0.92、1.10 秒，含文件列表和文件名复核的总时间约为 1.19、1.41 秒。前台样本以 Windows 报告对话框回到前台时为零点。后台跟随从调度开始记时，两种口径分别记录。
