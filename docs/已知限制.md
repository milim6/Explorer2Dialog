# Explorer2Dialog Windows 11 MVP 已知限制

## 应用和权限

- 实际跳转支持可识别的现代 Windows 标准文件打开及保存对话框。传统 Win32 对话框识别后跳过导航。Qt、Chromium 自绘界面和其他自定义文件选择界面只有在实际弹出符合标准结构的系统对话框时才适用。
- 本机 Fluent 2025 R2 的 File → Read → Case 和 CFX-Pre 2025 R2 的 Open Case 已确认使用本版无法导航的窗口。两者保留各自原有目录。[真实软件实测](测试报告.md)
- 目标进程须位于同一交互桌面且与 Explorer2Dialog 具有相同完整性级别。不同或未知级别被跳过。普通权限联合运行已通过，管理员目标的桌面用例待人工复核。[完整性控制](https://learn.microsoft.com/en-us/windows/win32/secauthz/mandatory-integrity-control)
- 打包目标为 Windows 11 x64。实测版本为 Build 26300.9974。Explorer 标签子窗口匹配和文件窗口 UIA 结构依赖 Windows 实际控件布局。其他系统版本和布局需要复测。

## 目录与窗口状态

- 缓存保留最近有效的文件系统目录。主页、此电脑、搜索结果等虚拟位置没有可用文件路径。如果最终活动标签未能确认，当前打开的窗口可能被跳过。
- 中文、空格、`+`、`#`、`%` 和多级本地目录已实际验证。UNC 可进入路径规范化流程，真实共享的在线、延迟和权限行为尚待复测。扩展设备路径 `\\?\` 或 `\\.\` 和超出当前路径处理能力的路径不在本版支持范围内。
- 后台同步使用最近活动的标准文件窗口，以及目录树能定位的本地盘符路径。UNC 和目录树无法匹配的目标在切回对话框时尝试前台导航。多个文件对话框同时打开时，以最近活动的一扇为准。
- 导航前核对完整性级别，前台输入前核对焦点和用户操作状态。地址栏正在编辑时保留当前编辑。人机几乎同时发送输入、不同比例缩放和其他应用的自定义焦点流程仍需做压力复测。

## 性能与诊断

- 本机记事本复测从切回到读取新目录为 0.917–1.102 秒，两次样本。UIA 提供程序、文件系统或负载可能拉长时间。同步 UIA 调用挂起时，超时会撤销该工作项的输入资格，已发出的调用等提供程序返回。两个工作槽同时挂起时，新窗口可能被跳过。[计时口径和样本](测试报告.md)
- 默认日志只记录状态、错误码和窗口标识，实际完整路径仅在 `--diagnostics` 模式写入。退出诊断运行后路径仍留在该次日志中，按日志轮换周期保留。
